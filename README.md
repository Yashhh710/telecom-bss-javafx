# Telecom SIM Card Activation & Billing System

Java Programming Case Study 60 implemented using JavaFX, OOP, Collections, CRUD, validation, exception handling and billing logic.

## Requirements covered

- Classes and Objects
- Constructors
- Enum: PREPAID / POSTPAID
- StringBuilder invoice generation
- ArrayList customer/plan/SIM storage
- LinkedList usage history
- HashMap SIM number -> customer
- TreeMap bills by date
- CRUD operations
- Searching
- Sorting
- JavaFX GUI
- Exception handling
- Input validation
